独立入口为 `scripts/windows/Cleanup-LocalHistory.ps1`，只接受矩阵和本地私有配置一致的 `localmysql.testhut.top:23306/aisocialgame`。它不注册 HTTP 接口、定时任务或跨环境数据迁移。

先运行 `-Mode dry-run -PlanFile <仓库外新文件>`，保存具体 ID、旧记忆片段、数量和保留数据指纹。停止本地后端后，以同一清单运行 `-Mode apply -PlanFile <清单>`。执行时重新选择候选并核对指纹，在事务内清理从属记录和旧记忆，再核对结果；重复执行返回零删除。

结构变更使用新增的 `20261029_retire_credit_holds.sql`，移除三个废弃分配字段；历史 SQL 源文件保持冻结。`schema.sql` 是当前 51 表的纯建库快照，包含先前快照遗漏的现行参与关系、点赞、结算锁、结算记录和临时积分批次，不包含历史数据回填。
