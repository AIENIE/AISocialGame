# 群聊式房间体验改版

## 实现范围

覆盖谁是卧底、狼人杀、海龟汤的房间准备、对局和结算。房间使用独立视口布局，桌面左侧玩家栏、手机横向玩家栏，中央为公开发言和事件，底部为当前操作。全站导航、钱包和在线人数条不再占用对局空间。

- 准备阶段读取房间席位，空座位打开邀请 / AI 选择；规则按需展开。
- 对局阶段显示发言正文、座位、对象、已有神态动作和问答引用；规则及 AI 设置不挂载，闲聊入口位于底部且打开后只读。
- 投票、复投与角色技能只提供服务端 `legalActions` 中的目标；选人后统一确认。揭票后的票数、票向在玩家区域显示。
- 身份 / 词语为紧凑标签；查验记录、狼队建议及药量仍遵循服务端个人 / 队伍可见范围。
- 海龟汤区分讨论、提问、解答，展示次数成本，最终解答及揭晓需要确认。
- 历史抽屉按轮次展示，分页加载；事件 ID 去重、公开序号排序，断线后补齐缺口。向上阅读保持位置，底部阅读跟随新发言。
- 普通失败保留草稿，提交中阻止重复操作；阶段 token 变化清除过期操作，新 archive 重置本局状态。
- 结算状态优先于房间 WAITING 状态，聊天恢复输入，提供复盘及下一局入口。
- 新增界面文案覆盖简体中文、繁体中文和英语。

未改变回合、次数、胜负规则；未改版大厅、个人中心、独立观战及回放页；未发版。

## 代码结构

`RoomExperience` 组织三个阶段，三种游戏页面仅提供游戏 ID。`GameRoomFrame`、`RoomPlayers`、`GameTimeline`、`RoomActionDock`、`RoomGameDetails` 分别承接框架、玩家、发言、操作及详情。`useRoomTimeline` 管理历史补齐，`useRoomActionController` 管理选人、草稿及确认。

后端新增 `PublicLogMetadata.project`，实时状态和分页日志使用同一个公开字段白名单，提供可选 `content`、`correlationId`、`publicSeq`、`voteResult`。只有 PUBLIC 事件进入公开记录；私密角色、词语、推理等不会通过该投影公开。旧事件缺少新增字段时直接保留原文，不拆解中文日志，不需要数据库结构迁移。

## 本地验收中修复的问题

- 标准 Windows 启动暴露出 Hikari 连接池启动后再次绑定 `connection-test-query` 的问题。移除两个配置中多余的 `SELECT 1`，由 JDBC 驱动进行连接有效性检查。
- 实际 SSO 授权码交换因 Java 不信任本地 CA 而失败。复用已有工作分支的最小修复：通过明确配置的证书集合构建 SSO HTTP 客户端，本地配置引用现有 user-service gRPC 信任证书；保留 HTTPS 主机名验证，错误证书配置直接失败。未修改公共服务、私有环境文件或系统证书设置。
- 浏览器离线时，已有 WebSocket 可能尚未关闭，导致操作区仍可提交。新增浏览器 online / offline 监听，离线立即关闭连接并禁用操作，恢复联网后等待新的同步握手完成再开放操作；新增两个回归测试。
