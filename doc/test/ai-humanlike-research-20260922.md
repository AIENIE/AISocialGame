# 当前 AI 真人感研究：证据、风险与下一步

后续执行更新：用户已选择先优化正常生成的“交流目的与发言尺度”，降级留待下一期。该切片已升级为 social-v2.8 / 输入 v3 并通过离线门禁，见[实现与测试报告](ai-conversation-20260922.md)。以下 v2.7 研究、历史样本及当时建议作为历史保留；其中“优先修降级”的建议已被上述用户选择取代，不能作为当前执行顺序。真实模型效果仍待验证。

日期：2026-09-22。研究对象为当前工作区 `social-v2.7`、四款完整 Persona 和三款玩法。方法是源码核对、历史真实评阅复核和已有工程结果分析。本次没有启动服务、调用模型、调整参数或预算；没有为当前版本补造质量评分。

## 1. 当前能下什么结论

**已具备支持自然互动的工程基础，尚未证明当前 AI 能稳定达到较高真人感。**

框架方面，最新标准 L2 后端 512 通过、25 外部跳过，前端 58 通过；此前本机真实 MySQL 隔离验证通过。旧版本确有真实对局经历，但当前冻结版本尚未完成真实六局，且当前共享数据库目标有 13306/23306 冲突。不能把“离线框架通过”写成“当前环境全部跑通”。见[只读预检](readonly-preflight-20260922.md)。

质量方面，最近一次已有完整 30 情境真实评阅来自 **social-v2.2**：

| 维度 | 历史均分 | 有效样本 |
|---|---:|---:|
| 自然度 | 3.320/5 | 25 |
| 回应针对性 | 3.767/5 | 30 |
| 人格连续性 | 3.600/5 | 30 |
| 情绪与行动一致性 | 3.600/5 | 30 |

四项均未达到既定 4/5。历史四局已提交决策 fallback 为 9/58（15.5%），生成延迟均值 17.32 秒、P95 45.20 秒。它们是旧版样本结果，不能作为当前版本的测量值；评分由编码代理完成，不是独立人工盲评。详细范围见[历史报告](../ai-game-realism-v2-quality-recovery.md)。

R1～R4 及收尾实现已增加结构化记忆、信息来源、承诺状态、完整人格、输入精简和诊断。这些修复使真人感更可实现、问题更可定位，但 mock 通过不能证明真实模型已经表现自然。

## 2. 真人感应看哪些行为

目标是“明确标识为 AI、但像同桌朋友一样参与”。核心证据是：接住刚才的问题，记得自己的立场，在新信息出现时有理由地坚持或改变，敢于按人设行动，也能在别人需要空间时停止说话。

- **语言**：表达长度适合当下；不反复总结规则、道歉、强调理性或口头禅。短句本身不保证自然。
- **行动**：投票、提问、保留资源、诈身份与公开/私下策略能形成可解释的关系。允许判断错误和策略性违约，不强制每次兑现，也不为“像人”随机犯错。
- **社会互动**：认得谁质疑了自己、谁提供了帮助；合作不等于附和，保守不等于永远不表态。
- **人格连续性**：差异体现在选择问谁、承担什么风险、何时站边及如何改判，不能仅凭名字、口吻或表情判定。

沿用已有四项评分，不临时增加第五项总分或更换通过门槛。上面的行为作为逐例证据。主持是裁判，优先准确、不泄底，单独评估；不要求主持和玩家一样试探或伪装。

## 3. 已核对的问题与待验证假设

| 项目 | 证据层级 | 发现与意义 |
|---|---|---|
| 说让步却继续抢话 | 历史真实样本 | `turtle_soup:useful_silence` 先说“好啊二号你问。我只补一点”，随后继续解释整段推理。口头礼貌不等于实际让出空间；当前版本是否修复需复测 |
| 降级后人格趋同 | 当前源码确定行为 | 狼人杀 fallback 用固定谨慎话术，卧底也常回到“先保留判断”；这些路径没有按完整 Persona 选择风格。海龟汤 fallback 主要复述最近裁决或 PASS。高频降级会削弱人物辨识度，当前发生频率未知 |
| 降级动作与原立场可能断开 | 当前源码确定机制，具体后果待验证 | 狼人杀 `choose` 用局、玩家、轮次及机会的哈希选合法目标；即使先过滤已查验对象，最终选择仍不读取已有怀疑或承诺。这保证确定性与合法性，不保证承接前述立场；不能把兜底造成的变票直接归因于模型性格 |
| 提示词可能使不同人物趋向同一种解释风格 | 待真实验证 | 系统提示包含大量事实、承诺和格式约束，也要求贡献新内容；人格虽明确区分，但多个角色仍强调依据、修正和克制。可能产生“每次都解释完整”的倾向，不能仅凭提示长度断言已发生 |
| 有记忆不等于稳定的社会行为 | 当前结构确定，质量待验证 | 关系保存为有限信任值和事件，情绪为单一名称、强度及按轮恢复，更新主要由模型提出。足以提供连续性线索，但不证明人物能在不同关系和压力下保持稳定行为；暂不据此主张扩建复杂情绪系统 |
| 反思不等于已形成自主学习 | 当前源码确定 | 轮末反思记录判断变化和承诺，`truthAssessment=UNKNOWN`、`nextPlan=UNSPECIFIED`；对已有跨局候选写入的是固定通用经验。这是可核对记录基础，不能宣称已经学会个体化策略 |
| 轮转和延迟可能影响体验 | 当前机制及历史测量，现版影响待测 | 海龟汤按座位轮转提供有限 AI 机会，模型仍可 PASS；狼人杀和卧底本来就有回合规则，不能把按规则轮流说话直接判为机械。应测是否实际抢话、无贡献仍发言以及等待后只回套话 |
| 输出示例可能造成选项位置偏好 | 待真实验证 | 输入示例填入第一个合法目标，提示同时说明不要默认选择。应观察是否存在无依据首目标偏好；目前没有证据证明模型受其影响 |

关键代码依据：

- `backend/src/main/resources/game-knowledge/social-player-system.txt`、`model/PersonaPresets.java`：正常生成的表达及人格约束。
- `engine/v2/werewolf/WerewolfRuleSet.java` 的 `fallback/choose`；另外两款规则的 `fallback`：故障时实际发言和行动。
- `service/ai/v2/AiMemoryServiceV2.java` 的 `snapshot/commit/finishGame`、`AiRoundReflection.java`：情绪、关系和反思能力的实际边界。
- `service/ai/v2/AiPromptProjection.java` 的 `outputExamples`：目标示例。

以上缩写 Java 路径均相对于 `backend/src/main/java/com/aisocialgame/`。历史原文依据为仓库外 `game-realism-v2/recovery-20260916/user-criteria-review.json`；本研究只引用公开发言，不复制私人观察、汤底或凭据。

## 4. 下一批如何研究和改进

**先建立当前版本基线，再按真实问题做小范围修复。** 不把后续工作扩展成框架重建，也不先堆叠语气词、随机表情或额外等待时间。

1. **关闭真实评测前置缺口。** 核实数据库实际映射、调用方/模型状态及原持久预算，按既有执行条件取得授权。通过前继续做离线证据分析，不消耗真实请求。
2. **复用已冻结的 R5 评测。** 120 个同情境四人格决策、48 个真实规则驱动连续步骤、12 个主持案例，随后六局。连续步骤必须覆盖判断—新证据—行动—后续承接。12 个先导样本计入正式集合，不能因效果不好重抽或隐藏失败。先导只能筛查明显问题，不能证明长期连续性。
3. **分别评模型与最终体验。** 正常生成、修正成功、合法 fallback、无响应分列。既看有效模型输出是否自然，也看玩家实际遇到多少降级、等待和断裂。相同事件编号或动作合法不等于回应有针对性；精确文字不重复也不等于没有语义套话。
4. **给机械表现做可核对标注。** 在现有审查材料中注明答非所问、泛化套话、过度解释、口头让步未让步、无依据改票、人格趋同及策略性伪装；每项关联实际样本、事件和动作。没有承诺就是没有，不为了评测强迫模型承诺或改判。
5. **按证据选择修复切片。** 若降级是主要来源，先处理超时原因以及降级动作的历史承接；若正常生成也冗长，先让输出紧扣当次交流任务；若四人格行动趋同，再调整具体行为指导。先保留合法性与秘密边界，不增加额外裁判 RPC。改动后生成新版本，保留旧失败证据，不能拼接跨版本结果宣布通过。

当前最值得先做的离线切片是**降级动作是否承接已有立场**：使用同一观察分别检查正常动作和 fallback，核对投票目标、此前公开立场及已有承诺；明确区分模型主动违约与系统降级改变动作。目标是减少无依据断裂，不是强制履约或把猜测升级为事实。此处为研究建议，本轮未修改生产逻辑。

## 5. 验收与研究边界

沿用既定门槛：单情境与连续序列四维分别评估，总体及各 Persona 均需达到 4/5；完整对局和多人格评测两组 fallback 各不高于 10%；边界、合法动作、覆盖及六局条件全部满足。未完成的样本不能从分母中消失，无响应不填零分或臆测分数。

满足这些门槛可以支持“在这些任务中达到预设自然互动标准”，仍不能单凭编码代理评分声称与真人不可区分。若后续希望提出更强的人类体验结论，应另行安排真实参与者评阅，预先固定方案、保留 AI 标识并控制评审偏差；本次没有招募、联系或开展此类研究。

本次仅新增研究文档和 M1 记录，未修改生产代码、冻结样本、评分门槛或原始证据；不需重复构建/L2。**M1-R5 真实评测及总体 L4 继续保持未完成。**
