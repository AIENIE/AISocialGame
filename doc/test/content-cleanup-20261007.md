# 用户访问边界与真实内容清理验收

目标仅为本地 AISocialGame；未部署预发布或生产。保留任务开始前的九个无关修改。

## 实现

- 用户公开路由为首页和指南；SSO 回调单独保留。受限页面仅在身份校验成功后挂载。
- 网络校验失败保留标签页 token 并支持重试；401 清理会话，普通 403 保留身份。登录回跳保存并校验站内路径。
- 按身份和 token 创建查询缓存，取消并清除旧缓存；退出或切换身份卸载房间、弹窗、聊天和轮询，HTTP/SSE 请求随 token 更换取消。
- 删除好友、本地成就、本地回放，以及无实际行为的页面控件。旧成就入口显示功能不可用。
- 钱包各接口独立显示加载、错误和真实数据；写操作完成后重新读取。服务端认证新增兼容字段 `balanceAvailable`，展示读取失败不返回伪造的零余额，身份登录不依赖余额可用。
- 管理台校验通过后才加载业务页面，读取失败不展示默认统计；管理台保持独立简中文案。
