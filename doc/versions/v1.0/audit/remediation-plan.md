依据：2026-09-26 用户批准的 Plan 1 — Direct implementation。

按以下五批执行，保留原审计报告和已有工作区开发成果：

1. MNT-001/002、SEC-007/008：统一类型检查、版本化迁移清单、依赖升级和漏洞门禁。
2. SEC-001/002/004/005/006：版本化独立会话、注销、统一房间与回放权限、STOMP 授权、实名社区与限流、删除不安全 TLS 回退。

4. PERF-003/004/005/008、MNT-003/004/005：调度隔离、代理与重连、幂等结算、存储隔离及业务错误码。
